# Efectos de sonido de los Reels

Generados con [earshot](https://github.com/Leonxlnx/earshot) (MIT): cada sonido se renderiza por código
(los realistas, a partir de modelos aprendidos de grabaciones de dominio público). Uso libre, sin atribución.
Para regenerar o añadir uno: `earshot make "<descripción>" -o generator/sfx/<nombre>.wav` (ver CLAUDE.md).

| Archivo | Uso típico |
|---|---|
| whoosh | transición entre escenas, bloque que entra rápido |
| swoosh | texto o tarjeta que se desliza |
| pop | icono o etiqueta que aparece |
| click | botón, selección, cursor |
| tick | contador de cifras (uno cada ~0,1 s como máximo) |
| ding | dato clave, aviso, notificación |
| cash | dinero que entra, ahorro |
| coin | moneda, céntimos, pequeño gasto |
| riser | tensión antes de revelar una cifra (su pico cae en el momento indicado) |
| impact | cifra grande o giro del guion |
| glitch | mito desmontado, error, corte brusco |
| type | texto que se escribe letra a letra |
| error | respuesta equivocada, "mito" |
| success | respuesta correcta, "realidad" |
| camera | foto que aparece |
| paper | titular de noticia que aparece |
| boom | golpe grave para la cifra clave o una palabra que entra de golpe (`punch`/`slam`) |
| caja | caja registradora: el resultado de una cuenta en euros |
| scratch | disco rayado: "mito", algo que no es lo que parece |
| swipe | mano que barre: comparación que entra de lado |
| aire | whoosh corto y fino: segunda palabra de un `slam` |
